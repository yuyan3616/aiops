## 1. Domain task model

- [ ] **H81-010** Add `AgentTask`, `AgentTaskStatus`, `AgentTaskResult`, `TaskPolicy`, `TaskError` types.
- [ ] **H81-011** Add centralized default policy values.
- [ ] **H81-012** Add task records to investigation runtime snapshot/server state without breaking existing Agent cards.
- [ ] **H81-013** Add unit tests for legal/illegal task state transitions.

Acceptance:

- A specialist invocation has a stable `taskId` before it begins.
- Every task ends in exactly one terminal status.
- Policy defaults are not duplicated across Agent implementations.

---

## 2. TaskScheduler

- [ ] **H81-020** Implement keyed per-Agent queue/lock (`concurrency = 1` per Agent kind).
- [ ] **H81-021** Implement global specialist concurrency limit (default `3`).
- [ ] **H81-022** Route `delegate_agents` through TaskScheduler instead of direct `Promise.all` on AgentManager.
- [ ] **H81-023** Preserve parallel execution for different Agent kinds.
- [ ] **H81-024** Add tests proving two Log tasks serialize while Log + Metric may overlap.

Acceptance:

```text
same Agent kind -> never concurrent
different Agent kind -> concurrent when global slot available
```

---

## 3. ContextBuilder

- [ ] **H81-030** Introduce `SpecialistExecutionContext` type.
- [ ] **H81-031** Implement `ContextBuilder` using case metadata + assignment + selected hypothesis/evidence summaries.
- [ ] **H81-032** Extend `delegate_agents` schema with optional `evidenceIds` and `hypothesisIds`.
- [ ] **H81-033** Replace inline specialist prompt assembly with ContextBuilder output.
- [ ] **H81-034** Add deterministic Evidence selection limit (`maxEvidence`).
- [ ] **H81-035** Add tests proving unrelated full Agent transcripts are never included.

Acceptance:

- `AgentManager` no longer chooses cross-Agent context itself.
- Specialist input is inspectable and bounded.

---

## 4. BudgetGuard

- [ ] **H81-040** Count Specialist tool calls in one canonical location.
- [ ] **H81-041** Enforce `maxToolCalls` before executing the over-budget call.
- [ ] **H81-042** Track Pi turn count using supported AgentSession events.
- [ ] **H81-043** Enforce `maxTurns` via session abort and typed error.
- [ ] **H81-044** Enforce per-task new-Evidence count (`maxEvidence`).
- [ ] **H81-045** Add budget exhaustion tests.

Acceptance:

- Prompt instructions are not the only protection against loops.
- Budget failure returns a typed task error and terminal state.

---

## 5. Timeout and cancellation

- [ ] **H81-050** Add investigation-level `AbortController` lifecycle.
- [ ] **H81-051** Add per-task wall-clock timeout with real `session.abort()` propagation.
- [ ] **H81-052** Cancel queued tasks when investigation aborts.
- [ ] **H81-053** Prevent new tasks from starting after abort signal.
- [ ] **H81-054** Add `POST /api/rca/incidents/:id/abort`.
- [ ] **H81-055** Add minimal Pi-chat-aligned stop UI while a run is active.
- [ ] **H81-056** Add cancellation/timeout tests verifying no orphan Agent run continues.

Acceptance:

- User can stop an investigation.
- Queue drains as cancelled, not silently executed later.
- Running Pi Specialist sessions receive abort.

---

## 6. ToolGuard

- [ ] **H81-060** Extract/centralize Agent-tool ACL guard from current gateway behavior.
- [ ] **H81-061** Add server-side `limit`, array-size and string-size caps independent of TypeBox schemas.
- [ ] **H81-062** Validate/normalize query time ranges.
- [ ] **H81-063** Add output row/serialized-size caps before LLM return.
- [ ] **H81-064** Validate Evidence output and prevent filesystem/answer-key path leakage.
- [ ] **H81-065** Add tests for unauthorized tool, oversized request, invalid window and oversized result.

Acceptance:

- Tool Gateway remains factual and backend-specific.
- Guard layer can reject unsafe/unbounded calls before DuckDB executes where possible.

---

## 7. Task events and tracing

- [ ] **H81-070** Add task lifecycle event types to shared RCA event contract.
- [ ] **H81-071** Publish `task.created/started/completed/failed/cancelled/timed_out`.
- [ ] **H81-072** Add correlation fields (`investigationId`, `runId`, `taskId`, `agent`, tool/evidence IDs where relevant).
- [ ] **H81-073** Expose task information in snapshot in a lightweight form.
- [ ] **H81-074** Ensure existing UI reducer ignores or handles new events safely.
- [ ] **H81-075** Attach the same correlation IDs to existing Langfuse-compatible execution metadata where practical.

Acceptance:

- One failed task can be traced from delegation -> Agent -> Tool -> Evidence/error.

## 11. Deferred items — do not implement in v8.1

These items are intentionally deferred:

### v8.2

- SQLite `InvestigationRepository`.
- Durable checkpoint.
- Append-only persisted EventLog.
- Server restart Resume.
- Interrupted-task rerun semantics.

### v8.3

- `NormalizedQuery` across modalities.
- Evidence coverage/subset matching.
- RawRef query-result reuse beyond exact cache.
- Reuse/token/scan metrics.

### v8.4

- Ground-truth evaluator.
- Multi-case / 103-case benchmark runner.
- Accuracy/cost/latency benchmark reports.

If implementation pressure suggests one of these is needed early, update the spec/roadmap first rather than introducing it implicitly.
