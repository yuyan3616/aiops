# 会话级自带模型配置（BYOK）实施约定

## 目标

系统模型可用时继续按原有链路调用。用户可在当前浏览器页面为一个会话提供 OpenAI Chat Completions 兼容的 HTTPS Base URL、模型 ID 和 API Key；主 Agent、RCA Expert 与标题生成必须使用同一模型上下文。自带模型调用失败不得回退到系统 Key。

## 凭证边界

- API Key 只保留在当前页面内存及服务端活跃会话的临时模型运行时内；不写入 `models.json`、Pi session file、conversation/investigation JSON、事件、SSE、日志、URL 或浏览器存储。
- 切换新会话时清除页面上的自带模型配置；页面刷新、重新打开历史会话、服务重启后须重新输入。运行中的异步 Expert 可持有本次运行所需凭证，直到任务取消或结束。
- 配置提交及消息提交走 HTTPS 请求体；后端不返回 Key。运行期间不得更新配置。凭证缺失时阻止自带模型继续调用，不得使用系统模型代替。
- 自定义目标只允许 HTTPS、经过批准的模型服务域名。第一版不开放任意域名的服务器端代理；新增服务商需要审核域名和协议。
- 用户界面说明：本服务后端会临时接触 Key，并把调查上下文发送给用户所选模型服务。

## 状态与失败

| 状态 | 行为 |
| --- | --- |
| 系统模型可用 | 新会话无需配置，按原有流程调用。 |
| 系统模型缺失或返回认证失败 | 提示可配置个人模型；保留已生成的会话和调查数据。401 只表示凭证被拒绝。 |
| 自带模型配置完成 | 当前会话的后续主 Agent、Expert 和标题任务使用该配置。 |
| 自带模型认证/限流/超时 | 展示统一的安全错误信息和重新配置入口，不回退系统模型；取消时通知运行中的 Expert。 |
| 页面刷新或运行时重启 | Key 不恢复；历史可读，下一次调用需重新配置。 |

## 安全与兼容验收

1. 用户 A 的模型运行时不能出现在用户 B 的模型列表或调用链中。
2. 子 Agent 并行、重试和标题生成不得使用其他会话的 Key。
3. 所有错误路径都不得输出 Key；任意格式的 Key 不依赖固定前缀正则来脱敏。
4. 测试系统模型可用、不可用、自带模型成功/失败、刷新、取消、会话切换和历史查看。
5. 无账号的公开部署还需访客会话隔离，保护历史与 RCA 接口；不能把知道 conversation ID 当成授权。

## 上线前阻断项

当前仓库的 `/api/conversation` 列表、会话详情、SSE 以及 `/api/rca` 接口尚未绑定访客身份。任何能访问公开站点的人都可能读取或操作别人的调查，独立的 RCA 接口还可能调用容器里的系统模型。自带 Key 的会话级隔离不能解决这些现有的公开接口问题。完成匿名访客隔离、旧数据迁移策略和 RCA 接口的独立鉴权前，不应将此改动作为公开多用户服务部署。

允许的模型域名由服务端 `BYOK_ALLOWED_HOSTS` 逗号分隔配置；未设置时使用代码中的默认服务商域名。当前仅支持 OpenAI Chat Completions 兼容接口、文本输入和固定的 64k/4096 模型能力参数，实际模型兼容性需要按服务商验证。
